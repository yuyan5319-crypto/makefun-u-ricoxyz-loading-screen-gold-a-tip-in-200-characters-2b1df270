# Loading Screen Gold: A Tip in 200 Characters

One sharp, funny loading-screen tip for stressed developers and AI coding
agents — a single line of 165 characters, written to land mid-build.

## The tip

> Tip: the AI agent rewriting your code is winging it too — it just never sweats, never sleeps, and still has to ask you what the function was supposed to do. Breathe.

The joke is the partnership: the agent is winging it too, it just never
sweats — and the punchline is that it still has to ask the human what the
code was supposed to do. No coffee, no deadline, no compile joke.

## Run

Requires Node 22 or later. No dependencies, no network, no secrets.

```sh
node main.ts
```

This writes the tip to `./output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), as UTF-8 text
of 1–200 characters, mode 0644.
